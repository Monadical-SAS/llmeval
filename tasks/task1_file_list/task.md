# Create File List JSON

## Overview
Create a JSON file that lists all files in the current working directory and its subdirectories.

## Learning Objectives
- File system traversal
- JSON data structure creation
- Path handling and file discovery

## Problem Statement
You need to create a program that discovers all files in the current directory tree and outputs them in a specific JSON format. The output should be a file named `files.json` containing a JSON object with a single key "files" whose value is an array of all file paths relative to the current directory.
